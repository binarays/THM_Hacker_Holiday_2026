# Hacker Holiday 2026
[TryHackMe's](https://tryhackme.com) Hacker Holidays 2026 is a free 14-day cybersecurity event where participants complete a new hands-on challenge each day. Set in the fictional Byte Lotus resort, it covers topics like **OSINT**, **web security**, **cloud**, **forensics**, and **AI**. Players earn raffle entries for prizes as they build practical cybersecurity skills.
